# Changelog

## [0.1.0] - 2026-11-09
### Changed
- **Release v0.1.0**: Initialize the hub-api control plane service: application scaffolding with centralized Pydantic settings and strict fail-closed validation; security enforcement via TCP origin allowlisting, API-key authentication, and HMAC-SHA256 webhook signature verification against raw request bytes; a database layer scoped to a single-UUID deletion domain with dry-run inspection before execution; a LibreDesk webhook receiver pipeline with bounded-memory deduplication, async daemon-thread dispatch, and sub-three-second acknowledgment; and diagnostic endpoints for health checks, client IP resolution, and non-sensitive config reporting.
